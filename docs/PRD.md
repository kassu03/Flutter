# VocaLytics 제품 요구사항 정의서
> **2026-11-24 범위 변경:** 앱 내 녹음 파일 저장·선택 재생·녹음 삭제 기능은 제외한다. 마이크는 실시간 음높이 측정과 유지율 계산에만 사용하며, 완료한 연습 시간과 유지율 기록은 계속 저장한다. 아래 기존 녹음·재생 관련 요구사항보다 이 변경 사항을 우선한다.

## 1. 프로젝트 개요

VocaLytics는 목표 음을 선택하고, 마이크로 입력한 목소리의 음높이를 보면서 연습하는 앱이다. 완료 후 연습 시간과 목표 음 유지율을 확인하고, 저장된 녹음을 선택해 다시 들을 수 있다.

목표는 Android 기기 한 대에서 핵심 흐름을 시연하고 Flutter의 상태 관리, 역할 분리, 비동기 처리를 설명하는 것이다. 출시·서버 운영·다양한 기기 지원은 이번 과제의 범위에 포함하지 않는다.

앱이 제공하는 값은 목표 음에 가깝게 유지한 정도다. 믹스보이스·두성·가성이나 발성 건강, 종합적인 노래 실력을 평가하지 않는다. 한 사람이 조용한 환경에서 연습하는 상황을 기준으로 한다.

## 3. 사용자 흐름과 화면

### 3.1 연습 준비

사용자가 목표 음을 선택하고 시작 버튼을 누른다. 목표 음은 반음 단위로 선택하며, 보컬 표기 기준 1옥타브(C3~B3), 2옥타브(C4~B4), 3옥타브(C5~B5)를 선택 범위로 사용한다. 표준 음 표기와 주파수를 함께 표시하며 실제 검출 성능은 시연 기기에서 확인한다.

기록을 불러온 뒤 마이크 권한과 녹음 시작이 성공하면 연습을 시작한다. 최초 실행의 빈 기록은 정상 상태다. 기록 읽기 실패는 빈 기록으로 처리하지 않고 안내와 재시도를 제공한다.

목표 음과 허용 폭은 회차 시작 시 고정한다. 녹음이 자동 저장되며 앱이 활성 상태일 때만 시간이 쌓인다는 점을 안내한다.

### 3.2 연습 화면

현재 음높이와 목표선을 표시하고, 목표 범위 안·높음·낮음·측정 불가를 글자와 색상으로 구분한다. 최근 음높이 그래프, 앱 활성 연습 시간, 완료 및 취소 버튼을 제공한다.

무음이나 검출 불확실 구간은 이전 음높이로 채우거나 0Hz로 표시하지 않는다. 그래프에 빈 구간을 표시한다. 완료 전에는 남은 최소 시간을 안내한다.

### 3.3 완료와 결과

완료 버튼을 누르거나 활성 시간이 10분에 도달하면 녹음을 멈추고 결과를 집계·저장한다. 처리 중에는 로딩을 표시하고 중복 완료 요청을 막는다.

완료 화면에 앱 활성 연습 시간, 측정 가능 시간, 유지율 또는 측정 시간 부족 안내, 녹음 저장 상태를 표시한다. 처리가 끝나거나 오류 안내를 확인하면 다음 연습으로 이동할 수 있다.

### 3.4 기록과 재생

캘린더에서 날짜를 선택하고 해당 날짜의 회차를 확인한다. 원하는 회차의 재생 버튼을 눌러 녹음을 듣는다. 재생·일시정지·정지·위치 이동을 제공한다.

동시에 하나의 녹음만 재생하며 새 연습을 시작하면 재생을 종료한다. 녹음 중 재생은 허용하지 않는다. 앱이 비활성 상태가 되면 재생도 일시정지한다.

녹음만 삭제할 때는 확인 안내를 표시하고 연습 시간과 저장된 유지율은 유지한다. 삭제한 녹음은 다시 들을 수 없다.

## 4. 시간과 유지율 규칙

### 4.1 앱 활성 연습 시간

앱이 활성 상태이고 녹음 입력이 정상적으로 진행되는 시간만 누적한다. 권한 요청과 녹음 준비 시간은 제외한다. 이 시간은 실제로 소리를 낸 시간과 다르다.

- 60,000ms 미만: 완료 불가, 취소 가능
- 60,000ms 이상: 사용자가 완료 가능
- 600,000ms 도달: 자동으로 한 번만 완료 처리
- 앱 비활성·화면 잠금: 녹음과 시간 측정 정지
- 앱 복귀: 녹음 재개를 자동 시도하고 성공한 뒤 시간 측정 재개
- 재개 실패: 정지 상태를 유지하고 재시도 또는 취소 안내
- 취소: 임시 녹음과 측정 자료를 버리고 연습 기록을 만들지 않음

일시정지 시간을 녹음 파일에 무음으로 삽입하지 않는다. 중단 전후의 분석 버퍼를 섞지 않는다.

### 4.2 목표 음 판정

초기 허용 폭은 ±50센트다. 경계값 −50과 +50도 성공으로 인정한다.

`센트 편차 = 1200 × log2(측정 주파수 / 목표 주파수)`

유효한 측정의 편차 절댓값이 50 이하이면 목표 범위 안이다. 화면에 반올림한 값으로 성공 여부를 판단하지 않는다. 음 이름이 같아도 옥타브가 다르면 같은 목표로 보지 않는다.

### 4.3 유지율

`목표 음 유지율 = 목표 범위 안 시간 / 측정 가능 시간 × 100`

음높이가 검출되고 품질 조건을 만족한 구간만 측정 가능 시간에 포함한다. 무음, 검출 실패, 불확실한 값, 처리 누락은 분모에서 제외한다. 품질 조건은 마이크 시제품에서 확인한다.

시간은 겹치지 않는 측정 구간으로 합산한다. 분석 창이 겹친다고 시간을 중복 합산하지 않으며 측정 가능 시간은 앱 활성 연습 시간을 넘지 않는다.

| 조건 | 저장과 표시 |
| --- | --- |
| 활성 1분 이상, 측정 가능 시간 10초 이상 | 시간·녹음·유지율 저장 |
| 활성 1분 이상, 측정 가능 시간 10초 미만 | 시간·녹음 저장, 유지율은 null, 측정 시간 부족 표시 |
| 측정 가능 시간 10초 이상, 목표 범위 안 시간 0초 | 정상 결과인 0.0% 표시 |

10초는 연속 시간이 아니라 누적 측정 가능 시간이다. 유지율은 원본 값을 보존하고 화면에서 소수점 한 자리로 반올림한다. 측정 가능 20초 중 범위 안 15초라면 75.0%다.

## 5. 저장과 기록 표시

### 5.1 저장할 데이터

| 항목 | 내용 |
| --- | --- |
| 식별 정보 | 회차 ID |
| 날짜·시간 | 시작 날짜, 시작·완료 시각, 앱 활성 연습 시간 |
| 목표 | 선택 음·목표 주파수·허용 폭 |
| 결과 | 측정 가능 시간, 범위 안 시간, 유지율 또는 측정 시간 부족 상태 |
| 녹음 | 앱 내부 파일 경로와 사용 가능·저장 실패·삭제됨 상태 |

완료 기록은 기기 내부 데이터베이스에, 녹음은 앱 전용 폴더에 저장한다. 정상 저장된 기록과 녹음은 앱을 껐다 켜도 유지된다. 앱 제거 후 복구와 강제 종료 중이던 작업의 복원은 구현하지 않는다.

### 5.2 날짜와 그래프

회차 전체 시간은 시작 당시 기기의 현지 날짜에 귀속한다. 자정을 넘겨 완료해도 시작 날짜를 유지하며 실제 완료 시각은 별도 저장한다. 같은 날짜에 5분과 7분을 연습하면 12분으로 합산한다.

- 캘린더 최초 선택: 오늘
- 월 변경: 해당 월 1일 선택
- 시간 그래프: 선택한 월의 일별 앱 활성 연습 시간, 기록 없는 날은 0
- 유지율 그래프: 선택 날짜의 회차별 결과를 시작 시각 순서로 표시, 축은 0~100%
- 측정 시간 부족: 0% 막대를 만들지 않고 해당 회차에 부족 안내 표시

저장에 성공한 데이터를 기준으로 캘린더·목록·그래프를 함께 갱신한다.

### 5.3 기본 오류 처리

| 상황 | 처리 |
| --- | --- |
| 마이크 권한 거부·시작 실패 | 이유 안내, 시간 누적 없이 다시 시작 가능 |
| 녹음 중 입력·파일 쓰기 실패 | 입력과 시간 정지, 오류 안내, 최소 시간에 따라 완료 또는 취소 |
| 집계 실패 | 오류 안내 후 다시 연습 가능, 작업 복구는 제공하지 않음 |
| 녹음 저장 실패 | 가능한 경우 시간·결과는 저장하고 녹음 없음 표시 |
| 기록 저장 실패 | 저장되지 않았음을 안내, 화면에 결과가 남아 있으면 저장 재시도 또는 종료 |
| 재생 파일 없음·재생 실패 | 재생 불가 안내, 시간·결과 유지 |
| 녹음 삭제 실패 | 실패 안내, 삭제 성공으로 표시하지 않음 |

저장 공간의 사전 예측은 제외하고 실제 저장 실패를 처리한다. 저장 재시도 시 같은 회차 ID를 사용해 중복 기록을 방지한다. 저장·집계가 실패해도 오류 화면에서 나와 새 연습을 시작할 수 있어야 한다.

## 6. 기술 구성과 수업 요구사항

### 6.1 도구 후보

| 역할 | 초기 도구 후보 |
| --- | --- |
| 앱 화면 | Flutter |
| 마이크 PCM 입력 | record |
| 음높이 계산 | pitch_detector_dart |
| 녹음 재생 | just_audio |
| 기록 저장 | sqflite |
| 앱 내부 파일 위치 | path_provider |

도구의 버전과 최소 Android 버전은 프로젝트 및 시연 기기의 호환 조건을 확인해 정한다. 위 조합은 아직 검증 완료된 구성이 아니다.

시제품은 하나의 마이크 입력을 음높이 계산과 녹음 파일 쓰기에 사용한다. 전체 음성을 메모리에 계속 쌓지 않고 파일에 기록한다. PCM 입력을 WAV로 저장해 재생하는 흐름을 먼저 검증한다.

### 6.2 비동기 처리

실시간 음높이 계산은 연습 동안 유지되는 별도 Isolate에서 처리하는 방향으로 시제품을 만든다. 입력 데이터마다 compute를 새로 호출하지 않는다.

완료 후 측정 구간의 시간과 유지율을 집계하는 순수 계산에 compute를 사용한다. 마이크·파일·데이터베이스 작업은 해당 계산 함수와 분리한다. 인위적으로 계산량이나 대기 시간을 늘리지 않는다.

실시간 화면은 측정 상태로 갱신하고, 완료 집계는 FutureBuilder로 대기·성공·오류를 표시한다. 화면 재구성만으로 집계 작업이 다시 시작되지 않도록 Future를 보관한다.

### 6.3 상태 끌어올리기와 역할 분리

캘린더, 목록, 그래프가 공유하는 기록과 선택 날짜는 공통 부모에서 보관한다. 자식은 전달받은 상태를 표시하고 콜백으로 변경을 요청한다.

화면 표시, 목표·시간 검증, 마이크 입력·음높이 계산, 파일·기록 저장의 책임을 분리한다. 과제에 필요한 규모로 구성하고 사용하지 않는 확장 기능은 만들지 않는다.

| T13 | 녹음 재생 중 새 연습 시작 | 재생 종료 후 녹음 시작 |
| T14 | 저장 실패와 재시도 | 안내, 중복 기록 없음, 다음 연습 가능 |
| T15 | 캘린더 날짜·월 변경 | 목록과 두 그래프의 조회 범위 일치 |

센트 계산과 시간 경계는 단위 테스트로, 버튼·로딩·오류 표시는 화면 테스트로 확인한다. 마이크·잠금·녹음 재생은 실제 기기로 확인한다. 시연에서는 목표 선택 → 연습 → 완료 → 결과 → 재생 → 기록 조회 순서로 보여 준다.

### 문서 변경 안내

v2.2는 기말 과제 범위로 간소화한 버전이다. 강제 종료 작업 복구, 버전별 재분석, 정교한 공간 예측, 여러 기기의 성능 검증 요구를 제외했다. 기존 핵심 연습 규칙과 Flutter 학습 요구사항은 유지한다.

### 2026-11-24 완료 정책 변경

기존 최소 1분·최대 10분 자동 완료 규칙을 대체한다. 앱 활성 연습 시간 20초 이상부터 사용자가 완료 버튼으로 종료·저장한다. 최대 시간에 따른 자동 완료는 제공하지 않는다. 일시정지는 누적 시간을 유지하고, 중단은 기록 없이 종료한다. 연습 중 목표 변경이 가능하며 현재 시간 기록에는 마지막 목표 음을 남긴다. 여러 목표에 대한 유지율 집계 정책은 별도 구현 전 확정한다.
